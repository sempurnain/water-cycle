# 🌊 AQUA ADVENTURE
### Explore the Water Cycle Through Interactive Learning!

**AQUA ADVENTURE** is an interactive web-based 3D educational platform designed for Grade 5 elementary school students to learn about the water cycle through immersive visual experiences, educational games, and engaging learning activities.

The platform transforms science learning into an exciting adventure, helping students understand the water cycle through exploration, interaction, and collaboration.

---

## 🎯 Project Overview

AQUA ADVENTURE is developed as an innovative learning medium for elementary education, focusing on the water cycle (Siklus Air) in Grade 5 IPAS.

By combining interactive 3D technology, gamification, and educational content, this platform aims to create a more engaging, enjoyable, and meaningful learning experience.

## ✨ Key Features

- **Interactive 3D Learning:** Explore the water cycle through immersive visual experiences.
- **Educational Games:** Learn scientific concepts through interactive challenges.
- **Solo Mode:** Play and complete learning challenges individually.
- **Duel Mode:** Compete with another player in educational challenges.
- **Squad Mode:** Collaborate with teammates to complete missions.
- **Teacher Dashboard:** Support teachers in managing classroom learning activities.
- **Interactive Simulations:** Discover how water moves through different stages of the water cycle.

## 💧 Learning Materials

The learning content focuses on four main stages of the water cycle:

1. **Evaporation (Evaporasi):** Water changes into water vapor due to heat from the sun.
2. **Condensation (Kondensasi):** Water vapor cools and forms tiny water droplets, creating clouds.
3. **Precipitation (Presipitasi):** Water falls from clouds as rain.
4. **Collection and Runoff (Mengalir):** Water flows and collects in rivers, lakes, and other bodies of water.

## 🚀 Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone https://github.com/sempurnain/water-cycle.git
```

### 2. Navigate to the project directory

```bash
cd water-cycle
```

### 3. Install dependencies

```bash
bun install
```

### 4. Start the development server

```bash
bun run dev
```

Open the local URL displayed in your terminal to access the application.
